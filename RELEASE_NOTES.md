Initial release of Kuanfu Outliner Focus.

- Automatically expand and scroll the Outliner to the active object.
- Toggle from the Outliner header or Filter popover.
- Manual reveal command and adjustable update interval.
- Native selection synchronization; no external dependencies.

Download **kuanfu-outliner-focus-v1.0.0.zip**, then use Blender Preferences → Add-ons → Install from Disk.

已在作者的 Blender 5.2.2 Octane 环境验证启用、自动跟随、开关及偏好设置保存。声明最低 Blender 4.2，其他版本尚未逐一验证。
